ESPN Fantasy Connection

Past seasons (e.g. 2025 or earlier) route through ESPN's leagueHistory endpoint automatically.

How the connection works

The fetch button routes the ESPN request through a public CORS proxy (trying a couple in sequence) so the browser doesn't block reading the response — this makes public leagues fetch directly with no setup. For private leagues, SWID/espn_s2 are attached to the request; ESPN's own read API only recognizes them as real cookies, and browsers won't let page JavaScript set a Cookie header on any request, proxied or not — so authentication can still fail depending on which proxy is reachable at the moment. If that happens, the app auto-falls-back to: open the API URL below in a browser tab while logged into ESPN, copy the JSON, paste it in the box below.

Paste raw JSON (fallback)

Skip ESPN entirely and type everything into the Content tab.

League History (all-time)

One request, every past season. ESPN's leagueHistory endpoint returns an array of all completed seasons when it's called without a seasonId — so there's no year-by-year loop to get rate-limited. That single array feeds the Rivalry Vault (all-time H2H) and the League Record Book. Requires League ID above.
