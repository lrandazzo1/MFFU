# Optional podcast beds

Place licensed `intro.mp3` and/or `outro.mp3` here to mix short tracks beneath
the first and last speech turns. Each file must be at most 5 MB. The tracks
are decoded at 44.1 kHz stereo, kept within the speech episode's duration,
and ducked by 12 dB while speech is detected. If absent, the episode is
speech only. The deployed functions include this directory.
